# N9raw Support

N9raw's GitHub organization is primarily a technical project space. It is not the main support channel for students.

## General N9raw questions

For general questions about N9raw, use the official website or contact channel:

- Website: [www.n9raw.com](https://www.n9raw.com)
- Contact: [contact@n9raw.com](mailto:contact@n9raw.com)

## Public information corrections

If you find public N9raw information that may be inaccurate, outdated, or incomplete, use the correction route rather than opening a generic technical issue:

- Français: [Corrections](https://www.n9raw.com/fr/corrections/)
- العربية: [التصحيحات](https://www.n9raw.com/ar/tashihat/)

## Privacy and data-rights questions

For privacy or personal-data rights questions, use [privacy@n9raw.com](mailto:privacy@n9raw.com).

Do not post personal data in GitHub issues, pull requests, discussions, screenshots, logs, or code samples. This includes student identifiers, phone numbers, credentials, private messages, and other sensitive information.

## Security vulnerabilities

Do not report vulnerabilities through a public issue. Follow the private reporting guidance in [SECURITY.md](SECURITY.md).

## Repository-specific technical issues

Use a GitHub issue only when the affected repository explicitly enables issues and the request is genuinely about that repository's code, documentation, or technical behavior.

A repository may publish more specific support instructions. Repository-specific guidance takes precedence over this organization-wide default.
