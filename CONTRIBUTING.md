# Contributing to N9raw

Thank you for your interest in N9raw.

N9raw is not currently an open contribution program by default. Unless a repository explicitly says that public contributions are welcome, please coordinate with N9raw maintainers before submitting code, content, data, or large documentation changes.

Repository-specific contribution guidance takes precedence over this organization-wide default.

## Contribution principles

When a contribution is invited or a repository explicitly accepts contributions:

- keep the change small, scoped, and tied to a clear purpose;
- use a pull request rather than changing `main` directly;
- include relevant tests and documentation for meaningful code changes;
- preserve French and Arabic/RTL behavior for user-facing changes where applicable;
- follow the repository's security, privacy, accessibility, and review requirements; and
- do not weaken an existing verification, permission, privacy, security, or rollback control without explicit approval.

## Data and privacy

Never submit real student personal data, credentials, authentication tokens, production secrets, private messages, database exports, or privacy-sensitive logs to GitHub.

Use synthetic or anonymized fixtures by default. Screenshots and test evidence must be privacy-safe.

## Factual and educational content

Do not submit unverified factual guidance as if it were authoritative. Important claims such as deadlines, eligibility rules, fees, admissions conditions, official endorsements, institutional contacts, or opportunity requirements need an appropriate source and human verification before publication.

## Rights and files

Do not contribute copyrighted educational resources, documents, images, or other files unless the repository's workflow has established the necessary rights or permission for the intended use.

## Security reports

Do not disclose vulnerabilities in a pull request or public issue. Follow [SECURITY.md](SECURITY.md).

## Need help first?

See [SUPPORT.md](SUPPORT.md) for the appropriate contact route.
